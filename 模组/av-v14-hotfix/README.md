# FVTT v14 Local Hotfix 0.6.22

当前核验基线为 Foundry **14.368**、PF2e **8.5.1**、Dice So Nice **6.4.2**、BBMM **1.4.11**、Grid **2.3.1**、Summons Assistant **2.20.2**。本模组按支持的主版本、实际 API 与函数源码契约安装适配；每项可在世界设置中关闭，刷新后生效。契约不匹配或检测到冲突时跳过，对应状态见：

```js
game.modules.get('av-v14-hotfix').api.status()
```

## 0.6.22 的上游维护

- 退役 Grid 距离与未绘制 Token 光环修补，使用上游 2.3.1；退役 BBMM 旧设置值恢复监听器，使用上游 1.4.11 的子菜单硬锁及通知。历史世界开关和 BBMM 规则保留，不迁移或删除。
- 五项 DsN 画质硬锁继续通过独立的 BBMM 规则读取器执行。读取器检查同步开关、当前账户、GM 豁免、真实注册表与规则结构；软锁、未注册项及非法值不强制执行。
- DsN 采用 6 主版本与 Foundry 14 主版本保护，并逐函数验证聊天、模型、队列、画质读写和预览契约。6.4.2 的新画质上下文已核验，阴影支持 `medium`。模型下载/解析与 worker/特效失败仍沿原生流程恢复聊天和下一批投骰，保留私密及交互规则。
- Summons 2.20.2 的到期回调仍需保护：只删除严格属于该到期效果的未链接场景 Token。改用 2 主版本加实际回调与 Document 所有权校验。
- PF2e 名称优化与 Sundry 的 PF2e 图标路径按实际函数及原生 Sprite 属性校验，解除已由这些契约覆盖的精确 PF2e 小版本标签。

DsN 状态中的 `modelStatus`、`modelPendingAtInstall`、`queueStatus` 与 `queueCompletionStatus` 分别说明模型、旧加载、启动队列和收尾消费者的安装情况。完成函数或消费者不匹配时只跳过相应路径；不使用超时强制成功。已卡住的旧客户端需要完整刷新。

## 历史维护记录

### 0.6.21 的 DsN 收尾补修

- 特效或物理 worker 收尾失败后，释放当前批次的等待，恢复聊天显示并继续后续投骰。
- 保留成功动画的等待、私密投骰和爆炸骰的顺序；只适配已核验的 DsN 6.4.1。

本次 Sequencer 4.2.3 的内部 await 取消补修单独部署，不包含在 Hotfix ZIP 中。

### 0.6.20 的 BBMM 并发补修

- 恢复硬锁值期间收到的新设置写入会正常安排下一次恢复，避免漏掉并发修改。
- 待处理标记在执行恢复前释放；原有值比较仍会跳过已经符合锁定值的事件。

### 0.6.19 的 Sundry 1.11.0 适配

- 支持 Sundry 1.11.0，继续跳过显示状态未变化时的效果列表读取。
- 1.11.0 已减少重复图标写入；效果列表仍在每次刷新时读取，因此这部分优化继续保留。
- 悬停、高亮、效果时长和其他模组管理的背景显示行为保持一致。适配不缓存 Actor 或效果列表。

### 0.6.18 的 Grid 2.3.0 适配

- **夹击**：继续使用 Grid 上游已修好的委托，本模组不覆盖 2.2.2/2.3.0 的夹击方法。
- **普通方格距离**：2.3.0 已修复重复扣减触及的问题；仍保留 PF2e 原生距离路径，保证数值一致。例如触及 10 尺、跨三个对角格时，PF2e 8.5.1 返回 15 尺，Grid 2.3.0 返回 20 尺；两者都在触及以外。
- **光环**：保留未绘制 Token 的空对象保护，并沿用 2.3.0 的实际距离与半径比较。碰撞、墙体、六角、无网格及自定义夹击继续走 Grid 原逻辑。
- 当时仅接受核验过的五个上游脚本哈希；这些安装分支现已随 Grid 修补退役。

### 0.6.17 的镜像验证补修

- **骰子初始化时机**：在 setup 阶段注册监听，并等待当前 DiceBox 的初始化完成。画板重建后重新安装队列恢复；旧画板的延迟回调不覆盖新画板。
- **自定义骰子模型加载失败**：补上 DsN 6.4.1 模型加载器缺少的错误回调，使下载、解析失败能进入聊天恢复流程。失败后可重试，不修改成功加载、私密骰或交互投骰的原生规则。
- 诊断状态增加 `modelStatus` 和 `modelPendingAtInstall`。正常完整刷新后应为 `installed` 和 `0`；已经卡住的旧客户端需要刷新。

### 0.6.16 的修复

- **聊天骰点恢复**：Dice So Nice 6.4.1 的动画启动失败后，释放该批次的等待，再继续原生聊天显示流程。修复原生异步队列丢失拒绝、导致后续骰点一起等待的路径；保留私密骰、交互式投骰、原生显示顺序及权限，不靠超时强制显示消息。
- **共享回合兼容**：Toolbelt 的临时参战者没有持久 ID；Reaction Checker 1.4.3 不再对它执行需要真实参战者的写入及出卡。Sustain Reminder 1.1.0 遇到无 Token 的真实 Actor 时仍正常生成维持提醒。
- **奴仆到期清理**：Summons Assistant 2.19.0 只删除与到期效果严格对应的未链接场景 Token，避免把世界 Actor 的空 parent 当作 Token 删除。
- **Grid 2.2.2**：恢复普通方格的 PF2e 原生距离计算，保留 Grid 的碰撞、光环、六角及无网格路径；补回光环处理空 Token 对象的检查。2.2.2 已修好的夹击委托不再由本模组覆盖。
- **Sundry 1.10.3**：核验其效果图标实现与 1.10.2 相同，恢复跳过无实际变化的重复效果计算。

Dice So Nice 的修复针对已复现的动画失败及队列等待，不涵盖网络断开、服务器未创建消息等其他缺失原因。上述回归不等同于正式世界的帧率验收。

## 安装、验证与回退

备份旧目录后，将本目录安装到 `Data/modules/av-v14-hotfix`，在需要的世界启用并完整刷新客户端。退役的 `scripts/patches/patreon.mjs`、`wayfinder-fog.mjs`、`wayfinder-fog-texture.mjs`、`grid.mjs`、`bbmm-locks.mjs` 应从部署目录移除。回退可恢复原目录，或关闭本模组后刷新。

安装清单使用 [av-v14-hotfix-v0.6.22 的 module.json](https://github.com/takaqiao/fvttAutoTranslateTool/releases/download/av-v14-hotfix-v0.6.22/module.json)，下载为同一标签的 `av-v14-hotfix-0.6.22.zip`。本仓库包含多个模组，不能用全仓库 `releases/latest/download` 作为此模组的清单。

运行 `node --test tests/*.test.mjs` 验证隔离回归。原生函数及源码哈希记录在 `tests/fixtures`；音频、设置操作符等测试需本地 Foundry 安装，可用 `FVTT_NATIVE_APP` 指定 `resources/app`。具体运行命令、数量、跳过项和部署哈希以本次修复回执为准。

本安装包只包含 Hotfix 自己的文件。另有第三方自动化的 GM 举盾结算修复、Sequencer 动画取消修复和 Trigger Engine 来源类型检查，单独记录与部署，不由此安装包代替。Narrator、Party Automation、Prime 及世界地图资源不属于本包。

本版没有通过删灯、删声音、改区域或改变画质目标来处理卡顿。实际一层地图右键拖动仍需使用修复后的客户端采样确认。
