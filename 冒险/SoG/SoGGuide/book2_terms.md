# 肆季鬼志 GM 指南 第二册 —— 术语表

本表在翻译 Book 2 前锁定，Book 3 起直接沿用。

## 优先级

| 层 | 来源 | 管辖范围 |
|---|---|---|
| A | `SoG/pf2e-season-of-ghosts.adventures.json` | 地名、场景、房间、NPC、剧情专名 |
| B | `pf2e_compendium_chn/compendium/pf2e.season-of-ghosts-bestiary.json` | 本 AP 的生物名 |
| C | `pf2_cn/zh_Hans` + `pf2e.spells-srd` / `equipment-srd` / `conditionitems` / `bestiary-*` | 规则、状态、法术、物品、怪物能力 |

**A 与 B 冲突时：生物名取 B，地点／NPC 取 A。** B 包的灵堕魔家族有成体系的「魔」字后缀，A 包只有零散译名甚至漏译。

首次出现用「中文 English」双语，后续纯中文。书名沿用 Book 1 的**肆季鬼志**（A 包作「鬼季」，但系列内一致优先）。
