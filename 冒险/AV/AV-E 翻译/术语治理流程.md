# 术语治理流程（cn.json）

脚本位置：`term_governor.py`

## 1) 提取术语候选

```powershell
python term_governor.py extract --target "AV-E 翻译/cn.json" --out-json "AV-E 翻译/terms_candidates.json" --out-csv "AV-E 翻译/terms_candidates.csv"
```

- `terms_candidates.json`：主文件（可编辑）
- `terms_candidates.csv`：表格预览

## 2) 可选：AI 自动补全 preferred_zh

```powershell
python term_governor.py ai-suggest --terms "AV-E 翻译/terms_candidates.json" --glossary "glossary.json" --model "gpt-5.2"
```

- 会优先使用 `glossary.json` 中已有映射
- 仅对 `preferred_zh` 为空的术语调用 AI

## 3) 手工审校术语

打开 `AV-E 翻译/terms_candidates.json`，重点改每项：

- `preferred_zh`：你最终想统一成的译名
- （可选）`aliases`：额外变体（数组）

## 4) 回灌到 JSON

```powershell
python term_governor.py apply --target "AV-E 翻译/cn.json" --terms "AV-E 翻译/terms_candidates.json" --backup "AV-E 翻译/term_apply_backup.json"
```

默认行为：

- 仅替换双语文本中的中文段（英文原文不动）
- 根据 `preferred_zh` 统一 `zh_variants` 与 `aliases`

可选参数：

- `--include-english`：英文词也替换为中文
- `--apply-english-part`：双语中的英文段也一起替换

## 5) 不满意可回退

```powershell
python term_governor.py restore --target "AV-E 翻译/cn.json" --backup "AV-E 翻译/term_apply_backup.json"
```

可多次迭代：

1. 调整 `terms_candidates.json`
2. `apply`
3. 检查
4. 需要则 `restore`
