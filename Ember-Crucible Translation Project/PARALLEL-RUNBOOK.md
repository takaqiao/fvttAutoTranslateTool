# 翻译批次处理

项目结构、格式约束和校验入口见 `PROJECT.md`。批次处理脚本位于 `3-常用脚本/parallel/`，译文校验与回写工具位于 `3-常用脚本/qa/`。

## 处理顺序

1. 对照英文基线生成待译清单，将文件分成互不重叠的批次。
2. 按清单中的字段路径填写译文。保留 HTML、UUID、行内命令及其他结构标记。
3. 检查每个批次是否覆盖清单中的全部字段，并核对跨批次术语。
4. 使用 `qa/apply_translations.py` 回写。该工具会检查英文源漂移、中文内容和标记结构；不要绕过检查直接覆盖合集文件。
5. 运行 `PROJECT.md` 第 5.4 节列出的完整校验，再在 Foundry 中检查显示和交互。

## 文件格式

回写批次使用扁平 JSON 对象：`{"<待译清单里的 path>": "<中文>"}`。只包含本批次负责的字段；未完成的批次须保留在临时工作目录中，不能作为完整结果提交。

## 临时目录

支持 `EMBER_PARALLEL_ROOT` 的脚本通过该环境变量指定批次目录。每次处理使用独立目录，保留英文基线、待译清单、译文和校验报告，便于复查。

提交前检查文件差异和校验结果，发布前另行检查 `module.json` 与发布标签的版本是否一致。
