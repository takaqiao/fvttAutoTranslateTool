## 翻译笔记 / 决策

1. **wiki canonical 替换**：本次发现 Ravounel 已有 wiki 中文「瑞瓦诺」、Kintargo「金塔戈」、Nidal「奈多」、Vyre「维里」、Nisroch「尼斯洛切」——均替换前几次会话中的临时译名（拉沃内尔/金塔尔戈/奈达尔/维勒/尼斯洛克）。最终 QA 时需全文统一刷一次。
2. **raja-krodha** = 化物罗刹（wiki 独立条目）— 比 s1 通用「罗刹」更精确（rakshasa 是大类）。
3. **vilderavn = 黑鸦爵**（pf2_cn 命中）。本次首次出现的 Cotrila 用「黑鸦爵 Cotrila」格式。
4. **belier devil = 诡谎魔**（pf2_cn / wiki 均未收 belier 独立条目；按 Latin belier = battering ram + 「谎言/伪装」拟）。Melandiar 是该种类。
5. **rokoa = 罗科亚**（wiki "Rokoa的保佑" 为 PF NPC 名，此处作枭鬼"精神领袖"职称，音译保留）。
6. **Order of the Torrent = 激流骑士团**（wiki 描述无标准中文，意译 + 与《地狱反叛者》创建背景一致）。
7. **shyinda = 炽印达**（自创音译）— 枭鬼李子烈酒。
8. **Highhelm stronghold plate = 高盔堡要塞甲**（wiki 命中）。前几次 s4 未出现过。
9. **stargazer**：作为物品（《珍宝宝库》35），不同于《野性嚎啸》Lizardfolk Stargazer；译为「观星仪」。
10. **bec de corbin = 鸟喙锤**：wiki 武器列表保留原名 + 拆毁 trait；按法语本意（鸦嘴）+ 双手锤兵器形态译。
11. **ferrugon = 锈铁魔**：pf2_cn 与 wiki 均未译；按 Latin ferrum (铁) + 词形「-gon」（形似 dragon 的怪物词尾）拟「锈铁魔」（区别于 rust devil 锈魔类）。
12. **dybbuk = 狄布克**（希伯来词 dibbuq 「附身死灵」音译）。
13. **Pezzack 三派系**：忠党派/反叛派/码头镇商人——译名结构对仗。
14. **Investigation Points = 调查点**（IP，与 s4 的 Infiltration Points 同缩写但语境不同；按上下文消歧）。
15. **战吼！(Battlecry!)**：本次首次引用此规则书；保留中文标题（PF 出版书的非官方中文社区惯例）。
