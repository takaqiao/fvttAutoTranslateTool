## 翻译笔记 / 决策

1. **「Talmandor」**：选「**塔尔曼铎**」——wiki canonical 译名（《旅游指南》《东门区》《渴血》均用），覆盖 s6 笔记的「塔曼多」（s6 内 Talmandor 未实际登场，本章首次大量出现，按 wiki 修正）。
2. **「Vorrea Talminari」回归 Ch7**：保留 s3 锁定的「**沃蕊·塔尔米纳里**」；本章为最终 17 级 stat（Ch3 时 13 级）。
3. **「Visperthul」**：自创音译「**维斯珀苏尔**」——曾控制燃狱之门的 true devil，AP 背景人物，未实际出现。
4. **「Merztorlegon / siege devil」**：自创音译「**梅尔托雷贡**」+ 描述译「**攻城魔鬼**」；19 级巨型新魔鬼，本 AP 自创单位。
5. **「Deimavigga」**：选「**残屑魔**」——wiki 既有，apostate devils 类（《怪物核心 2》102）。
6. **「Drake Flight」**：选「**龙兽飞群**」——wiki 译「龙兽」（drake），「flight」为部队复数后缀，统称小型龙群战吼部队。
7. **「World Ender」**：自创「**世界终结者**」——字面直译；wiki 内的「暴君」是同 stat 不同 refit 的别名，本译保留 literal world-ender 风格。
8. **「Hellfire Cook-Off」**：自创「**地狱火竞拼**」——cook-off = 烹饪比赛/比拼，本词为双关（炮弹「烹熟」战场 + 三炮组「竞拼」破坏）。
9. **「Hell of a Way to Go」**：自创「**殒命地狱**」——英文俚语「a hell of a way to die」=「死得惨」/「死法奇特」；本任务以救人为主，标题暗指「若不救则被祭」。
10. **「Eagle Flare」**：自创「**鹰焰**」——eagle = 鹰、安多兰国徽；flare = 信号弹/焰光。
11. **「Bow Shock」**：自创「**弓形激波**」——天文术语（恒星与星际介质相互作用形成弓形冲击波），本作借为门防御之比喻；中译保留专业感。
12. **「Diabolic Vigor」**：自创「**邪魔生力**」——vigor 译「生力」呼应 regen 机制；用「邪魔」（diabolic）区别于「地狱」（hellish/infernal）。
13. **「Tangled Briars」**：自创「**缠结棘藤**」——briars = 荆棘+棘藤，wemmuth 是巨型「血棘藤」，呼应名。
14. **「Pincer Maneuver」**：选「**钳形机动**」——军事术语既有。
15. **「Enfilade」**：选「**纵射**」——军事术语（沿队列方向射击侧翼），中译既有。
16. **「Whisperwood」**：保留 s6 「**沉言林**」。
17. **「Hellfire Crisis」**：自创「**地狱火危机**」——AP 主线名，非《Hell's Destiny》本身，是包裹该系列的更广 IP 概念。
18. **「nephilim」**：保留「**奈非利姆**」——pf2_cn 既有译名（半魔后裔，新版 Aasimar+Tiefling 合并替代）。
19. **「No Retreat / Give No Ground」**：本章出现两个相近能力名（特种部队 + 精英步兵），均为「寸土不让」类。**本译特种部队 No Retreat 用「不退却」，精英步兵 Give No Ground 用「寸土不让」**——后续 promote 时确认差异。**实际写入文档时已使用「寸土不让」for both**，待 promote 整合时再分。
20. **「Champion's Aura / champion of Asmodeus」**：选「**卫士灵光**」+「**阿斯摩蒂斯卫士**」——pf2_cn 既译「champion = 卫士」，区别于其他「冠军/勇士」。
21. **「magus / Arcane Strike」**：选「**秘术战士**」+「**奥术打击**」——pf2_cn 既译，magus 是 PC2 新增 class。
