## 翻译笔记 / 决策

1. **Sense Motive / Force Open / Pure Legion / sarglagon** — 4 个 PCN 与 wiki/term_map 冲突的术语，决定保留 AP 内部已用译法（前两个项目早期已建立），并在术语表上加冲突注记，由用户在最终 QA 决定是否全局对齐 PCN。
2. **Lady Scalpel = 手术刀夫人**（self，先前 s1+ 已用）— wiki 中可能有「剥皮刀女士」对应（数据未核实），目前保留 AP 内部用法。
3. **ayngavhaul / coarti** — wiki 无 CN 名，phonetic 译为「安加沃尔魔」「科阿提魔」，与 s1+ 同 NPC stat block 风格一致。
4. **Lector** — 切利亚斯阿斯摩蒂斯祭司头衔，译为「诵经师」（与 Lictor「执棒官」相区分）。
5. **Brine-Eye Cult** — 自创「咸眼邪教」，与 Brine（咸水）+ Eye（眼）相符。
